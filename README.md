# الصمت في المدينة العتيقة

لعبة قصة تفاعلية عربية (لهجة تونسية): رعب وخيال علمي في المدينة العتيقة بتونس. ٤٥ فصلا في ٣ أجزاء، ٥ نهايات، ألغاز، أجواء صوتية، وتعابير وجوه لثلاث شخصيات.

## التشغيل
افتح `index.html` في المتصفح. يجب أن تبقى الملفات الأربعة في المجلد نفسه.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة والتصميم، تحمّل الملفات الثلاثة بالترتيب |
| `images.js` | صور التعابير (فرح، حزن، خوف، غضب، دهشة) للشخصيات الثلاث |
| `story.js` | القصة والشخصيات والنهايات وإعدادات هذه اللعبة |
| `engine.js` | المحرّك العام القابل لإعادة الاستعمال في ألعاب أخرى |

## لعبة جديدة بالمحرّك نفسه
استبدل `story.js` و`images.js` وغيّر `GAME` في أعلى `story.js`. المحرّك يفترض ثلاث شخصيات مفاتيحها `a` و`y` و`s`.

## النشر على GitHub Pages
Settings ثم Pages ثم Deploy from a branch ثم `main` ثم `/ (root)`.
