# الصمت في المدينة العتيقة

لعبة قصة تفاعلية عربية (لهجة تونسية): رعب وخيال علمي في المدينة العتيقة بتونس. ٤٥ فصلا في ٣ أجزاء، ٦ نهايات (واحدة سرية)، ألغاز، أجواء صوتية، وتعابير وجوه لثلاث شخصيات.

## التشغيل
افتح `index.html` في المتصفح. يجب أن تبقى كل الملفات في المجلد نفسه (الخدمة دون إنترنت تعمل عبر GitHub Pages أو خادم، لا من فتح الملف مباشرة). عند تحديث اللعبة غيّر `V` في `sw.js`.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة والتصميم، تحمّل بالترتيب: images ← lang_ar ← story ← audio ← studio ← engine ← fx، ويسجّل `sw.js` |
| `images.js` | الصور الأساسية فقط (الشخصيات الثلاث وأول خلفيتين) وتُحمَّل مع الصفحة |
| `images2.js` | تعابير الوجوه وبقية الخلفيات، تُحمَّل كسولا بعد ظهور الشاشة الأولى |
| `fx.js` | مشاهد سينمائية بالكود (باب حقيقي يُفتح، قفل، بئر، نجوم...) بعد الألغاز وفي النهايات، وأجواء ضباب/غبار، ولمسات الانفعال |
| `sw.js` | Service Worker: تشغيل أسرع ودون إنترنت بعد الزيارة الأولى |
| `i18n.js` + `lang_tn.js` + `lang_ar.js` + `lang_fr.js` + `lang_en.js` | اختيار اللغة، النصوص المترجمة، اتجاه العرض، والرجوع للتونسية عند غياب مفتاح ترجمة |
| `story.js` | بنية القصة (الفصول والخطوات والمشاهد والرسوم) وتستدعي النصوص بمفاتيح `TR('c01.s3')` |
| `engine.js` | المحرّك العام القابل لإعادة الاستعمال: الحالة، الحوار، الكاميرا، الألغاز، النهايات، القوائم، واجهة `Engine` للتوسعة |
| `audio.js` | الصوت والأجواء مولّدة بالكود (دقّات بصدى، أصوات عارضة حسب المكان، مزاج الثقة) |
| `studio.js` | أدوات اختيارية: معالجة الصور، استبدال الصور، استيراد/تصدير القصة، مكتبة الصور (يمكن حذفه) |
| `manifest.json` + `icon-192.png` + `icon-512.png` | تثبيت اللعبة على الشاشة الرئيسية (PWA) |

## اللغات
اللغات المفعّلة: التونسية (`tn`)، العربية الفصحى (`ar`)، الفرنسية (`fr`)، والإنجليزية (`en`). يحمّل `index.html` ملف `i18n.js` قبل القصة؛ ويختار اللغة المحفوظة، أو لغة المتصفح عند أول تشغيل. يمكن تغييرها من القائمة ← الإعدادات. `lang_tn.js` هو مصدر الاحتياط لأي مفتاح ناقص. لإضافة لغة: أنشئ `lang_xx.js` بصيغة `LNG.xx={t:{...},rx:{...}}`، أضفها إلى `LANGS` في `i18n.js` وإلى `FILES` في `sw.js`، ثم ارفع رقم `V` في `sw.js`.

## لعبة جديدة بالمحرّك نفسه
استبدل `story.js` و`lang_ar.js` و`images.js` وغيّر `GAME` في أعلى `story.js`. المحرّك يفترض ثلاث شخصيات مفاتيحها `a` و`y` و`s`.

## النشر على GitHub Pages
Settings ثم Pages ثم Deploy from a branch ثم `main` ثم `/ (root)`.

ملاحظة: التقدّم محفوظ داخل المتصفح لكل رابط، فلا ينتقل تلقائيا بين الرابط القديم والجديد.

## مزايا المحرّك
- أنواع الألغاز: `seq` (نغمات/اتجاهات)، `code` (رمز رقمي)، `ord` (ترتيب عناصر: `o` العناصر، `a` فهارس الترتيب الصحيح).
- شريط تقدّم الفصل، زر ⏩ لتبديل سرعة النص، ولمس النص لإكماله.
- لوحة المفاتيح: مسافة/Enter متابعة، 1-9 اختيار، M القائمة، Esc إغلاق.
- ⏩ نقرة = تخطّي الجملة (نقرتان سريعتان = أكمل الكتابة وانتقل)، وضغط مطوّل = تبديل سرعة النص. سجل الحوار (☰ أو مفتاح H) يعرض آخر 15 سطراً.
- الإعدادات ← «تقليل الحركة» يوقف الاهتزاز والضباب والمشاهد الحركية. لحظة صمت تلقائية بعد مشهد اللغز، ومن القصة `{x:'hush 1200'}`.
- ملف `manifest.json` وأيقونتان لتثبيت اللعبة على الشاشة الرئيسية (PWA).
- دفتر الأدلة 📓 (أو مفتاح J) يفتح فوق اللغز دون إغلاقه، والأحدث أولا.
- تلميحات مدرّجة في الألغاز: خطأ أول عام، ثان يحيل للدفتر، ثالث التلميح الكامل.
- حافة حمراء خفيفة على المشهد حين تنزل ثقة أي رفيق تحت ٤.
- القائمة ☰ ← تصدير/استيراد الحفظ كملف JSON لنقله بين الأجهزة.
- شاشة النهاية تشرح سبب النهاية، وتنبيه عند تراجع الثقة تحت ٤.
- شاشة النهاية: «جرّب قراراً آخر» (يعيدك لفصل القرار الأخير) و«مشاركة» للنتيجة. تخطّي اللغز يظهر بعد ٤ أخطاء. نبض قلب خفيف حين تنزل الثقة تحت ٤.
- مشاهد سينمائية بعد كل لغز ولكل نهاية (لمس الشاشة = تخطي). من القصة يمكن تشغيل أي مشهد بخطوة `{x:'cine door'}`؛ الأنواع في أعلى `fx.js`.
- بطاقة الفصل تعرض عنوان الجزء عند بدايته، ووميض/خطوط سرعة خفيفة عند الدهشة والغضب والخوف.

## دليل المطوّر (استغلال المحرك وتطويره)
**بنية `engine.js`** مرتّبة في أقسام مرقّمة (الفهرس في أعلى الملف): الإعدادات ← واجهة التوسعة ← الحالة ← الواجهة ← الصوت ← المشهد ← لغة المشهد ← الحوار ← الألغاز ← النهايات ← الصور ← التعابير ← القوائم ← التشغيل. قاعدة: ما يعمل عند التحميل يوضع في «التشغيل» فقط.

**الإضافة دون تعديل المحرك** عبر كائن `Engine` (مثال كامل في `fx.js`):
```js
Engine.on('line', s => ...)            // كل سطر حوار | الأحداث: line, chapter, scene, trust, puzzle:won, ending
Engine.on('card:extra', () => '<p>نص</p>')   // HTML يُضاف إلى بطاقة الفصل
Engine.onGate('puzzle:won', (ctx, go) => { /* مشهد */ go() })   // قبل متابعة القصة؛ ctx.chapter
Engine.onGate('ending', (ctx, go) => go())                       // ctx.n رقم النهاية
Engine.puzzles.match = (p, c) => { ov(`...`); /* عند النجاح */ win(p, c.f) }   // نوع لغز جديد {k:'match',...}
Engine.ops.shake = async (a) => { ... }                          // أمر جديد داخل {x:'shake 300'}
```
**لعبة جديدة بنفس المحرك:** بدّل `story.js` (الفصول و`GAME`) و`lang_ar.js` (النصوص) والصور؛ أبقِ `engine.js` و`fx.js` و`sw.js` كما هي (غيّر `V` في `sw.js` عند كل تحديث).

**المشاهد السينمائية:** أضف نوعا جديدا في `KINDS` داخل `fx.js` (`html` للرسم، `snd` للصوت، `hide:1` لإخفاء الشخصيات)، ثم اربطه بفصل في `AFTER_PUZZLE` أو بنهاية في `AFTER_END`، أو شغّله من القصة بـ `{x:'cine النوع'}`. مشهد الباب يشقّ الخلفية الحقيقية عند `SPLIT` (موضع شقّ الباب في الصورة).

**اختبار شامل:** افتح اللعبة آليا (Playwright) وشغّل `start(nw())` ثم تقدّم بالنقر على `#dl` واختر عشوائيا من `#cx button` واحلّ الألغاز بـ `win(p,0)` حتى تظهر شاشة النهاية؛ إن لم تظهر أخطاء في الكونسول فالمحرك سليم.
- التموضع على الأرض: `SC2[الخلفية]=[مركز أفقي، خط القدمين، الارتفاع]` في `story.js`؛ صف قريب (أكبر وأدنى) وصف بعيد (أصغر وأعلى مع ضباب خفيف) وقدما كل شخصية على الأرض مع ظل تحتها. الشخصيات غير شفافة (التعتيم بدل الشفافية لغير المتحدث).
- **النهاية السرية (٦):** حرّروا الأصوات بثقة ٧+ لكلا الرفيقين، مع جمع كل الأدلة (`ALLJ` في `story.js`) وبلا أي خطأ أو تخطّي لغز (`G.err`). لكل نهاية نبرة بصرية (لون المشهد والعنوان) في `fx.js`.
- نوع لغز جديد `pick`: `{k:'pick', cl, o:[{t:'نص',iv:ثوانٍ},...], a:فهرس_الصحيح, h, r}` — خيارات لكل منها زر استماع، والجواب يعتمد على دليل في الدفتر (يُستعمل في الفصل 35).
- **المرحلة السينمائية:** مشاهد في لحظات القصة المفصلية عبر `{x:'cine النوع'}`: knock (دقّة)، shadow (ظلّ)، eye (عين الحلقة)، scan (مراقبة)، wave (صوت)، mute (يُسحب الصوت)، orb (كرة الأصوات)، title (بطاقة عنوان: `{x:'title سطر|سطر'}`). تُجمع بـ `;` مثل `{x:'cine wave; hush 800'}`.
